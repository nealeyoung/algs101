\problem\emph{(Section 8.2)}
In the ruins of Pompeii, the \href{https://en.wikipedia.org/wiki/House_of_the_Tragic_Poet#Vestibule}{House of the Tragic Poet} has a famous mosaic floor proclaiming ``Beware of the Dog.''   In  Boston, a less tragic and wealthier poet has commissioned a mosaic to be built from 1kg bars of solid gold, each 80mm by 40mm.  To know whether her desired mosaic can be built in this way, the poet needs to solve the following problem:

\begin{mylist}
\item[] \prob{Tiling by Bars} \dotfill \em
\item[\bf input:] a two-dimensional array $A[1..n, 1..m]$ where each entry $A[i,j]$ is either `\textsf{colored}' or '\textsf{white}', representing an $m\times n$ grid of square cells, each 40mm by 40mm and colored or white.
\item[\bf output:] `\textsf{yes}' if it is possible to place gold bars (each 80mm by 40mm) on the grid
  so that each bar covers exactly two colored grid cells, and each colored grid cell is covered by exactly one bar.
  If it is not possible, then `\textsf{no}'.
\end{mylist}

\vspace*{-0.2in}
\adjustbox{valign=b}{\hspace*{-0.1in}
  \parbox{4.5in}{
    \noindent\hspace*{-0.25in}
    \adjustbox{valign=t}{
      \includegraphics[width=0.5in]{homework_10_gold2.jpeg}
    }
    \adjustbox{valign=t}{
      \parbox{4in}{
        The gold bars can be rotated 90 degrees, but not split.  As an example, consider the pixel art on the right (not to scale).  Can the leaf be tiled in this way? 
      }
    }
    \medskip

    Develop a poly-time reduction $r$ from this problem to the \prob{Bipartite Matching} decision problem:
  }}~~\adjustbox{valign=b}{
  \includegraphics[width=1.75in]{homework_10_aa.png}
}

\begin{mylist}
\item[] \prob{Bipartite Matching} \dotfill\em
\item[\bf input:] bipartite graph $G=(U, W, E)$ and non-negative integer $k$
\item[\bf output:] `\textsf{yes}' if $G$ has a matching of size at least $k$, otherwise `\textsf{no}'.
\end{mylist}


\begin{enumerate}[label=(\alph*)]

\item
  Define your reduction $r$
  by defining, for every possible instance $A[1..n, 1..m]$ of  \prob{Tiling by Bars},
  what output $r(A)$ the reduction gives.
  The output will be a bipartite graph $G=(U, W, E)$ and integer $k$.
  Your definition must state precisely how $G$ and $k$ are defined for the given $A$.\footnote
  {{\bf Hint:} Imagine a checkerboard on the grid.  Any bar must cover exactly one red square and one black square.}

\item
  Show that your reduction is a \emph{polynomial-time} reduction,
  by explaining carefully how, given $A$, one can compute the output $r(A)$ in time polynomial in the input size, $n\, m$.

\item
  For your reduction $r$ to be correct,
  it must be that, \emph{for every  \prob{Tiling by Bars} instance $A$,
    the answer to $A$ is `\textsf{yes}' if and only if the answer to the \prob{Bipartite Matching} decision problem $r(A)$ is `\textsf{yes}'.}
  Show the ``if'' direction.
  Given an arbitrary \prob{Tiling by Bars} instance $A$,
  let $G=(U, W, E)$ and $k$ be the output of your reduction $r$ given $A$.  That is, $(G, k) = r(A)$.
  Describe carefully how, given any bipartite matching $M$ in $G$ of size at least $k$,
  one could obtain from $M$ a valid covering of $A$ by bars.

\item
  Now show the ``only if'' direction.
  Given an arbitrary \prob{Tiling by Bars} instance $A$,
  let $G=(U, W, E)$ and $k$ be the output of your reduction $r$ given $A$.
  Describe carefully how, given any valid covering of $A$ by bars,
  one could obtain a bipartite matching $M$ in $G$ of size at least $k$.

\item
  Let $R$ be the algorithm from Part (b) above that computes your reduction $r$ in polynomial time.
  Assume that there is a poly-time algorithm $B$ that solves the  \prob{Bipartite Matching} decision problem.
  Give pseudo-code for an algorithm that uses $R$ and $B$ to solve the \prob{Tiling by Bars} decision problem
  in polynomial time.
  Your algorithm may call $B$ and $R$ as subroutines.  You don't need to define $B$ or define $R$.
  Your pseudo-code should have just a few short lines.
  \emph{Hint: Section 8.2.4, Lemma 8.6.}

  You can use notation such as $B(G, k)$ to denote executing $B$ on a given instance $(G, k)$ of Bipartite Matching,
  and returning the result (`yes' or `no') as the value of the expression $B(G, k)$.
  You can use notation such as $(G, k) = R(A)$ to denote executing $R$ on input $A$,
  and storing the result ($r(A)$) in $G$ and $k$.

\end{enumerate}

if, for every $\epsilon>0$ (no matter how small)
decreasing the capacity of $(u', w')$ by $\min(\epsilon, \capac(u', w'))$ would decrease the maximum possible flow.
That is, for all $\eps>0$, in the flow network $G_\eps=(V, E)$ with edge capacities
\[
  \capac_\eps(u, w) = \begin{cases}

    \max(\capac(u, w) -\epsilon, 0) & \text{if } (u, w) = (u', w'),
  \end{cases}
\]

\paragraph{(b)} Give a long-form proof of the following lemma. 

\begin{lemma}
  Let $(u, w)$ be any edge in any $s$-$t$ flow network $G$ with positive capacities.
  Then $(u, w)$ is critical if and only if $(u, w)$ crosses some minimum-capacity $s$-$t$ cut $(S, T)$
  (that is, $u\in S$ and $w\in T$).
\end{lemma}

\problem[3 part (ii)] \emph{(Section 8.1)}
\textbf{\em Do this OR Problem 3 part (i), not both.}

Give a long-form proof of the conjecture below,
suggested by a student in Tuesday's class:

\begin{conjecture}\label{conjecture: problem 3 ii}
  Let $f$ be any maximum flow in any $s-t$ flow network $G$.
  Let $R$ be the set of vertices reachable from $s$ in the residual graph $G_f$.
  Let $(S, T)$ be \textbf{any} minimum-capacity $s$-$t$ cut. 
  Then $R\subseteq S$. 
  That is, every vertex reachable from $s$ in $G_f$ is in $S$.
\end{conjecture}

Recall that $(R, V\setminus R)$ is itself a min-capacity $s$-$t$ cut.
(See e.g.~the proof of Theorem 8.2 in Section 8.1.4.)
One interesting consequence of the conjecture is that,
for any two max flows $f$ and $f'$,
the set of vertices reachable from $s$ in $G_f$
is the same as the set of vertices reachable from $s$ in $G_{f'}$,
even if $f$ and $f'$ are different flows.

In your proof, use the following notation, as defined in Section 8.1:
\begin{mylist}
\item[$|f|$:] The value of a given flow $f$.
\item[$G_f$:] The residual graph for a given flow $f$.
% [review 2026-09-27] fix: L: set B written lowercase: 'w\in b' -> 'w\in B'
\item[$E(A, B)$:] The edges in $E$ from $A$ to $B$ ($E(A,B) = \{(u,w) \in E: u\in A, w\in B\}$).
\item[$f(A, B)$:] The flow from $A$ to $B$ (that is, the total flow on edges in $E(A, B)$).
\item[$\capac(S, T)$:] The capacity of an $s$-$t$ cut $(S, T)$ (that is, the total capacity on edges in $E(S, T)$).
\end{mylist}

And use the following observation, from the proof of Lemma 8.2:
\begin{observation}\label{obs: lemma 2}
  For any $s$-$t$ flow $f$ and $s$-$t$ cut $(S, T)$,
  $f(S, T) \le \capac(S, T)$ and $f(T, S) \ge 0$.  
\end{observation}
