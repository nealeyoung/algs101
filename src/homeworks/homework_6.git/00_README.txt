

## FILES INCLUDED HERE

00_README.txt -- this file

homework_6.tex --- Don't edit it. This is the main LaTeX source file.  It loads the other LaTeX files.  
                   Compile it (to homework_6.pdf) and read that PDF for further instructions. 

problem_0_answer.tex --- Edit this to add your name (and, if your course asks for it, your student ID).

problem_XX_answer.tex --- Edit each file of this form to add your answers for Problem XX:

   Replace the placeholders e.g. "\REPLACEME" with your answers.  Make
   sure each problem starts on a new page and follows the given format,
   with the previously existing text colored black, and the text you add
   colored blue, to make grading easier.

   Make sure that no \REPLACEME placeholders remain when you are done.

macros.tex --- Don't edit it.  It loads some LaTeX packages and defines some macros.  
first_page.tex --- Don't edit it. It contains the instructions on the first page.  
check_cycle.py --- Checks your cycle for Problem 5(a).  Run it with Python 3; see Problem 5(a).


## ONCE YOU'VE ADDED YOUR ANSWERS:

Once you've added your answers as described above, run LaTeX on
homework_6.tex to regenerate homework_6.pdf.  When you are ready,
submit homework_6.pdf (for example, to your course's submission system).

Each answer should be on the expected page in the expected place (as in
the original template) in your PDF.
