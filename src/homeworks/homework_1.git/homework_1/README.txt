

FILES INCLUDED HERE:

homework_1.pdf --- The result of compiling homework_1.tex with no edits.  Read it now for further instructions.

homework_1.tex --- The main LaTeX source file.  It loads the other LaTeX files.  Don't edit it.

problem_0_answer.tex --- Edit this to add your name (and, if your course asks for it, your student ID).

problem_1_answer.tex --- Edit this to add your answers for Problem 1.  
problem_2_answer.tex --- Edit this to add your answers for Problem 2. 
problem_3_answer.tex --- Edit this to add your answers for Problem 3.
problem_4_answer.tex --- Edit this to add your answers for Problem 4. 
problem_5_answer.tex --- Edit this to add your answers for Problem 5. 

In each of those files, replace the placeholders e.g. "\REPLACEME" with your answers.
Make sure each problem starts on a new page and follows the given format, with the
previously existing text colored black, and the text you add colored blue, to make
grading easier.  

macros.tex --- This file loads some LaTeX packages and defines some macros.  Don't edit it.
first_page.tex --- Contains the instructions on the first page.  Don't edit it.


FURTHER INSTRUCTIONS:

Once you've added your answers as described above, 
run LaTeX on homework_1.tex to generate homework_1.pdf.
When you are done, submit homework_1.pdf (for example, to your course's
submission system).
